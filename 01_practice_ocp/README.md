# 01 練習問題：物体持ち上げ動作における操作力最小化問題

## 概要

Balboa の起き上がり軌道を、間接法（勾配法）を主な手法として生成する予定だったため、
その準備として作成した。目的は次の 2 つ。

- 勾配法（最急降下法）を用いた最適制御問題の復習
- PythonとSymPy・CasADi・SciPyの習得

題材には、最適解が存在することが示されているシンプルな問題を選んだ。
## 問題設定
初期時刻$t_0$、終端時刻$t_f$、制御入力$u$

**状態方程式**

$$
\dot{x}_1=x_2\\
\dot{x}_2=\frac{1}{m}u-g
$$

**評価関数**

$$
J = w\cdot\frac{1}{2}\{(x_1-h)^2+x_2^2\}+\int^{t_f}_{t_0}\frac{1}{2}u^2dt
$$

**境界条件**

$$
x_1(t_0)=0,x_2(t_0)=0\\
x_1(t_f)=h,x_2(t_f)=0
$$

## ファイル

| ファイル | 内容 |
|---|---|
| ocp_sympy.py | 最急降下法（間接法）。ハミルトニアンの偏微分を SymPy で自動で求める |
| ocp_casadi.py | 直接法（CasADi＋IPOPT） |
| ocp_scipy.py | 随伴方程式を含む境界値問題として solve_bvp で解く |
| segway_hamiltonian_sympy.py | Segway モデルのハミルトニアンの偏微分を SymPy で求め、数値微分と比べて検算する |

## 実行方法

```
python ocp_sympy.py
```

必要なライブラリ：（numpy、sympy など）

## 結果

|---|---|---|

| 境界値問題（solve_bvp） | 53.381 | （ ） |
